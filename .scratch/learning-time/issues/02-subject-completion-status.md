# 02: 아이별 과목 완료 현황 및 활동 수 표시

**What to build:** 일일 리포트 응답에서 과목별 활동 내역(한글/영어는 `contentsHistory.dailyCourse`, 수학은 `contentsHistory.daily` 리스트 길이)을 파싱하여 아이별 카드 뷰에 과목 완료 현황을 표시합니다. 아이별 카드는 3줄 구조(1행 아이 이름, 2행 학습 시간, 3행 과목 완료 현황)로 구성되며, 기본 목표 개수(한글 6, 수학 5, 영어 8)를 기준으로 활동 수가 목표 개수 이상이면 과목명 앞에 `✔ `가 붙고 숫자는 항상 `(활동수/목표개수)` 형태로 표시됩니다. 아이가 구독하지 않은 과목은 과목 목록에서 완전히 제외되며, 구독 중이나 당일 활동이 0건인 과목은 `(0/목표개수)`로 안전하게 노출됩니다.

**Blocked by:** 01: 날짜 네비게이션 및 과거 일자 학습시간 조회

**Status:** done

- [x] 한글과 영어는 `contentsHistory.dailyCourse`, 수학은 `contentsHistory.daily` 리스트 길이를 활동 수로 안전하게 추출한다(null-safe).
- [x] 과목 구독 여부는 `users`(/user) API 응답 내 아이의 `userId` 존재 여부로 판정한다.
- [x] 아이가 구독하지 않은 과목은 표시 목록에서 완전히 제외된다.
- [x] 아이가 구독 중이지만 당일 활동이 0건이거나 리포트가 비어있는 경우에도 누락 없이 `과목명 (0/목표개수)` 형식으로 정상 표시된다.
- [x] 각 아이별 표시가 3줄(1행 아이 이름, 2행 `${minutes}분`, 3행 과목 현황)로 정렬된다.
- [x] 과목 현황은 기본 목표 개수(한글 6, 수학 5, 영어 8)를 기준으로 `✔ 한글 (8/6), 수학 (3/5), ✔ 영어 (13/8)` 포맷으로 쉼표로 구분되어 표시되며, 화면 너비에 맞게 자연스럽게 줄바꿈(wrap)된다.
- [x] 활동 수가 목표 개수 이상인 과목에만 과목명 앞에 `✔ `가 붙고, 미완료 과목은 체크 없이 표시된다.
- [x] 오늘뿐만 아니라 선택된 과거 날짜 조회 시에도 해당 일자의 활동 수와 완료 여부가 정상 계산되어 표시된다.
