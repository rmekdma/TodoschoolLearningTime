# 01: 날짜 네비게이션 및 과거 일자 학습시간 조회

**What to build:** 상단에 이전 날짜(`<`), 현재 선택 날짜(`M월 d일 (E)`), 다음 날짜(`>`)로 구성된 고정 네비게이션 바를 제공하여 사용자가 날짜를 자유롭게 이동하거나 DatePicker를 통해 특정 일자를 선택할 수 있게 합니다. 선택된 일자의 API를 호출해 해당 날짜의 아이별 학습시간을 조회하고, 오늘이 아닌 과거 날짜 조회 시에는 아래로 당겨 새로고침(SwipeRefresh)을 비활성화하며 다음 날짜(`>`) 버튼은 오늘일 때 `INVISIBLE` 처리합니다. DatePicker 확인 버튼 좌측에 '오늘' 버튼을 두어 원터치로 오늘 날짜로 복귀할 수 있으며, 고속 클릭 시의 레이스 컨디션 및 자정 경계값 오류를 방어합니다.

**Blocked by:** None (can start immediately)

**Status:** done

- [x] 상단에 `<  [M월 d일 (E)]  >` 고정 네비게이션 바가 표시되고, 가운데 날짜 버튼을 누르면 DatePicker가 열린다.
- [x] 상단 바는 스크롤 시 사라지지 않는 고정 헤더이며, 루트 뷰에 WindowInsets가 적용되어 상태바와 겹치지 않는다.
- [x] DatePicker의 maxDate는 `Asia/Seoul` 기준 오늘의 `LocalTime.MAX` Epoch millis로 설정되어 오늘 날짜가 안전하게 선택 가능하다.
- [x] DatePicker 확인 버튼 좌측의 '오늘' 중립 버튼(`BUTTON_NEUTRAL`)을 누르면 즉시 오늘 날짜가 선택되며 팝업이 삭제되고 오늘 데이터를 불러온다.
- [x] 날짜가 오늘인 경우 `>`(다음 날짜) 버튼은 `INVISIBLE` 상태여야 하며, 과거 날짜일 때만 노출된다.
- [x] 날짜 이동(`<`, `>`) 또는 DatePicker 선택 시 해당 일자(`yyyymmdd`)의 학습시간 데이터를 API로 조회하여 아이별로 표시한다.
- [x] 데이터 로딩 중에는 상단 네비게이션 버튼(`<`, `[날짜]`, `>`)이 비활성화되며, `lastRequestId`를 검증하여 이전 비동기 요청 결과(성공 및 실패 모두)가 현재 화면을 덮어쓰지 않도록 방어한다.
- [x] 조회 실패 시 상단 날짜는 사용자가 선택한 일자를 그대로 유지하며, 에러 뷰를 노출하고 상단 네비게이션 버튼을 다시 활성화하여 재시도/이동이 가능하다.
- [x] 날짜 바 아래에 작고 연한 회색 글씨로 마지막 확인 시각(`마지막 확인 HH:mm`, 로딩 중엔 `확인 중...`)이 표시된다.
- [x] 오늘 날짜를 조회 중일 때만 아래로 당겨 새로고침(SwipeRefresh)이 동작하고, 과거 날짜 조회 중에는 비활성화된다.
