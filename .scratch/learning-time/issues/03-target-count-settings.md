# 03: 아이별 목표 개수 설정 팝업 및 영구 저장

**What to build:** 아이 이름 옆에 `⚙️` 설정 버튼을 제공하여, 아이별로 각 과목의 일일 목표 개수를 커스텀 설정하고 기기에 영구 저장할 수 있게 합니다. 설정 창은 해당 아이가 구독 중인 과목만 입력 필드로 보여주며, 기본값(한글 6, 수학 5, 영어 8)을 placeholder로 안내합니다. 0~99 사이의 정수만 허용되고 0으로 설정 시 해당 과목은 항상 완료(✔)로 판정됩니다. 빈 값이 있으면 저장을 방지하며, 저장 완료 시 네트워크 재호출 없이 메모리 캐싱 데이터를 활용해 화면의 과목 현황을 즉시 재계산하여 반영합니다.

**Blocked by:** 02: 아이별 과목 완료 현황 및 활동 수 표시

**Status:** completed

- [x] 각 아이의 이름 우측에 `⚙️` 설정 버튼(최소 터치 영역 48dp)이 표시되고, 이름 텍스트가 길어도 버튼이 밀려나지 않도록 `weight=1f` 처리된다.
- [x] 설정 다이얼로그는 해당 아이가 구독 중인 과목에 대해서만 숫자 입력 필드를 제공한다.
- [x] 각 입력창은 기존 저장된 값을 채워 보여주며, placeholder(hint)로 기본값(한글 6, 수학 5, 영어 8)을 안내한다.
- [x] 입력창이 비어 있거나 0~99 범위를 벗어난 비정상 입력일 경우 저장을 차단하고 안내 메시지(토스트)를 띄운다.
- [x] 목표 개수를 0으로 설정한 과목은 활동 수가 0개여도 항상 완료(`✔ 과목명 (활동수/0)`)로 표시된다.
- [x] 저장 시 자격 증명과 분리된 `target_counts` SharedPreferences에 아이 이름을 키로 영구 저장되어 앱을 재실행해도 유지된다.
- [x] 저장 완료 시 네트워크 API를 재호출하지 않고, 메모리에 캐싱된 `currentResult` 활동 수 데이터를 사용해 즉시 화면의 3행 과목 현황 텍스트를 재계산하여 갱신한다.
